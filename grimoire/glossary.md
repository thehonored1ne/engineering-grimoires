# Grimoire Glossary

## Core Concepts

- **Grimoire:** A collection of skills for a specific engineering domain.
- **Skill:** A reusable procedure for completing a concrete engineering task.
- **Combination skill:** A skill that composes two or more existing skills into a larger workflow or new capability.
- **Class:** A broad capability category assigned to a skill.
- **Rank:** The expected complexity, scope, and autonomy required by a skill.

## Skill Classes

| Class | Definition |
| :--- | :--- |
| **Generation** | Creates new code, assets, boilerplate, or documentation. |
| **Synthesis** | Combines inputs into one structured deliverable. |
| **Validation / Audit** | Checks an input or result against defined rules and standards. |
| **Transformation** | Refactors or converts an existing structure. |
| **Extraction** | Isolates specific data, parameters, or code structures. |
| **Utility** | Performs a focused helper operation. |
| **Orchestration** | Coordinates multiple skills or workflow stages. |
| **Sanitization** | Cleans, scrubs, or masks sensitive or unsafe data. |

## Rank Classification

| Rank | Scope |
| :---: | :--- |
| **S** | Complex autonomous workflows and system-level changes. |
| **A** | Deep audits, refactoring, or multi-stage engineering work. |
| **B** | Structured synthesis, migrations, and component-level work. |
| **C** | Standard transformations, parsers, and formatters. |
| **D** | Focused extraction, validation, or simple transformations. |
| **E / F** | Small utilities and narrow text operations. |
